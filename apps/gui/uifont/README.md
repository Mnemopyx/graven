# The interface's font for fields and cells

`DejaVuSans.ttf` (DejaVu Sans 2.37, unmodified) is built into the GUI for
text fields and table cells (legend sheets, the expression line), where
legends' characters must show as they are typed. It is a proportional sans,
hinted for screens and readable at small sizes, and the interface's own
Bitstream Vera extended, so fields match the rest of the interface. It
covers Greek, mathematical operators and relations, arrows, sets, number
sets, brackets, super- and subscripts and key symbols, and carries an
OpenType MATH table.

Licence: `DejaVu-LICENSE.txt` (Bitstream Vera and Arev terms; DejaVu's
changes are in the public domain): free to bundle and redistribute with

Chosen 2026-11-18 over Inter (49 of 173 tested symbols missing), Source
Sans 3 (51), IBM Plex Sans (70) and Noto Sans Math alone (35 missing, ²
among them).
