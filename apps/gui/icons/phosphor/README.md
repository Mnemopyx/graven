# Phosphor icons (duotone)

Interface icons for Graven, from Phosphor Icons, `@phosphor-icons/core` 2.1.1
(https://phosphoricons.com), duotone weight, unmodified. MIT licence: see
LICENSE. Only the icons Graven uses are copied here; `apps/gui/icons.zig` lists
them, and copying another one in is all it takes to add it.
