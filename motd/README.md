# Messages of the day

The start screen shows `motd/<version>.md` for the running version of Graven, fetched at most once a day from this folder on the default branch and cached on each machine (see `apps/gui/motd.zig`). A `# ` line is a heading; a blank line ends a paragraph. Write the file for a version before it is released; edit it later to send news to everyone running that version.
