# Graven 0.0.0

The legend engine is now glyphic (engine v2) throughout: legends typed in LaTeX as KaTeX takes it, or a Typst-style syntax, with math between dollars.

Ctrl+\ edits an equation, a text run's math, or a selected key's text in place on the canvas: Tab goes through each structure's head and fields, and single keys on a head scale, nudge and turn it.

Text styles are glyphic style contexts: faces by role, rules, a base. Documents from before this version cannot be opened.
